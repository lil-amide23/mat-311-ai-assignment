# mat-311-ai-assignment
There were certainly benefits I saw to using AI for this assignment. Most important of these was that I was able to (most times) use AI to speed up what I already knew how to do. There are definitely drawbacks to doing this, though. I mostly felt mindless the whole time I was completing this assignment and did not learn any new information. Additionally, if I didn’t know enough pandas or python, I would not be able to change a specific part of a graph or analysis on my own – I’d have to use the LLM. The notebook was trying to use data wrangling and visualization to help see if fraudulent transactions on a credit card might be predicted based on commonanlities between transactions.

For example, ChatGPT outputted code which yielded a graph where the legend contained all green colors (there was no red to indicate a fraudulent transaction). I had to look for that and although I was able to use the LLM to correct the issue, I would be in a much worse place if I didn’t know how to fix the legend myself. Finally, LLM outputs are often incorrect, and one way I was able to verify the ChatGPT’s output integrity was by looking at the shape of the credit card dataset using the .shape() method.
